## How I Approach Data Problems

My focus is on building solutions that are not only functional but also reliable and maintainable.

- Validate data instead of assuming it is correct.
- Design repeatable workflows instead of relying on manual processing.
- Handle duplicates, missing records, and inconsistent source data explicitly.
- Include tests and reporting so results can be verified.
- Document setup instructions, assumptions, and business rules.

The repositories above contain implementations, documentation, and verification results for the workflows described.
